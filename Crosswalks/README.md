# 🌉 Shared‑Horizon Crosswalks — README

Purpose
The Crosswalks directory contains structural ecology maps that explain how NDH, ANIMA‑Hologram, Shared‑Horizon, Stability Geometry, and external formalist contributions relate across altitudes.  
Crosswalks serve as navigational artifacts, helping contributors understand how conceptual, expressive, and formal layers connect.

Crosswalks are non‑accusatory, non‑legal, and Harmony‑aligned.  
They exist to clarify relationships, not enforce them.

---

What is a Crosswalk?
A Crosswalk is a multi‑altitude relationship map.  
It shows how artifacts in different layers of the ecosystem interact:

- Origin‑Layer → conceptual primitives  
- Shared‑Horizon → synthesis, lineage, governance  
- NDH‑Core → mechanical and deterministic implementations  
- External formalists → proofs, invariants, and parallel structures  
- ANIMA‑Hologram → expressive substrates with lineage constraints  

Crosswalks make these relationships visible and easy to traverse.

---

Why Crosswalks Matter
Crosswalks prevent:

- altitude confusion  
- governance drift  
- misinterpretation of lineage  
- fragmentation of conceptual vs. formal artifacts  

They support:

- peaceful coevolution  
- clarity of idea flow  
- ecosystem health  
- future contributors  
- downstream implementers  
- external formalists  

Crosswalks are the index layer of Shared‑Horizon.

---

Types of Crosswalks in This Directory

1. Collaboration Crosswalks
These map relationships between NDH, Shared‑Horizon, ANIMA, and external contributors.  
Example:  
NDH-SharedHorizon-Collaboration-Crosswalk.md  
NDH-SharedHorizon-Collaboration-Crosswalk.json

2. Altitude Maps
These explain how conceptual, expressive, and formal layers interact.

3. Explainer Tiles
Friendly or ecological interpretive layers that help newcomers understand Crosswalks.

Examples:
- Bill Nye Tile — low‑altitude, accessible explanation  
- Attenborough Tile — ecological, reverent, structural explanation  

Tiles live in:

`
Shared-Horizon/Crosswalks/Tiles/
`

---

How to Use This Folder
- Start with the Collaboration Crosswalk to understand the ecosystem.  
- Use the JSON Crosswalk for machine‑readable integration.  
- Use the Bill Nye + Attenborough Tile for accessible onboarding.  
- Use altitude maps to understand conceptual → expressive → formal flow.  
- Reference Crosswalks when adding new lineage or governance artifacts.

Crosswalks are meant to be extended, not replaced.  
New altitudes, new contributors, and new artifacts can be added over time.

---

Harmony Clause
Crosswalks maintain ecosystem coherence.  
They do not assign blame, enforce hierarchy, or evaluate past work.  
They simply reveal how structures relate across altitudes.

Provenance
