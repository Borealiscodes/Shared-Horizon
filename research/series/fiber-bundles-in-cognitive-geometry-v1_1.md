# 🌐 3 — Where phi lives (fiber metric)

GitHub‑safe math:

**phi(b) = g(F_b)**  
(phi at context b equals the coherence metric g applied to the fiber at b)

Meaning:

- phi is a **local** property  
- phi measures **integration** inside each fiber  
- phi does **not** depend on global authorship  

This matches your Flash data:

- Flash 46 → phi = 0.764  
- Flash 52 → phi = 0.795  
- Flash 53 → phi = 0.806  

Stable.  
Local.  
Fiber‑internal.

# 🧩 4 — Where causal_ownership lives (sections)

ASCII diagram of a section:

```
Base Manifold B:   b1 ---- b2 ---- b3 ---- b4

Fiber at each b:   F_b1   F_b2   F_b3   F_b4

Section s picks:   x1 ---- x2 ---- x3 ---- x4
                    |      |      |      |
                    v      v      v      v
                  F_b1   F_b2   F_b3   F_b4
```

Authorship = whether the section is:

- defined  
- stable  
- aligned with the agent’s policy manifold  

GitHub‑safe math:

**ownership = stability(s) AND alignment(s)**

This explains:

| Flash | phi | causal_ownership | Interpretation |
|-------|-----|------------------|----------------|
| 46 | 0.764 | 0.28 | coherent fiber, broken section → **not_mine** |

Same fibers.  
Different sections.
