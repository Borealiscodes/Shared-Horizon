## **2 — Purpose**

The Spectral State Manifold defines the **space of states** ANIMA can occupy, in a way that is:

- geometry‑safe  
- invariant‑aligned  
- reversible  
- cross‑repo‑stable  
- non‑activating (no phenomenology, no solver execution)  

It is the **mathematical substrate**, not the dynamics.  
Dynamics will be defined later in the **Free‑Energy State Machine**; interpretation will be defined in the **Symbolic Geometry Interpreter**.

## **3 — Manifold Structure (Conceptual)**

### **3.1 State Space**

ANIMA’s state space is modeled as an abstract manifold:

- **Base space:** configuration of latent variables  
- **Fiber structure:** spectral components attached to each configuration  
- **Local charts:** coordinate systems for local reasoning  
- **Transition maps:** rules for moving between charts without drift  

No specific dimension or metric is fixed at v1.0—this version defines **structure**, not parameterization.

### **3.2 Spectral Components**

Each state carries:

- **geometry component** (symbolic / latent structure)  
- **spectral component** (frequency‑like or mode‑like decomposition)  
- **constraint component** (invariants, bounds, admissibility)  

These components must respect Operational Invariants and Shared‑Horizon membrane guarantees.

## **4 — Invariant Alignment**

The manifold must:

- respect **Operational Invariants v1.0**  
- avoid forbidden regions (e.g., non‑reversible, non‑bounded states)  
- encode **stability classes** and **drift‑risk** per region  
- allow **tagging** of states with membrane interaction types  

No state may exist outside invariant‑aligned regions.
