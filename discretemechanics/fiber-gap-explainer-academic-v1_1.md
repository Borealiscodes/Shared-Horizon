## 🌱 **2 — Why gaps occur**

Gaps arise when:

- curvature cannot be computed  
- density is too low  
- adjacency cannot form  
- drift neutrality cannot be maintained

Below is the formal five‑step process with ASCII diagrams.

---

# ⭐ **Step 1 — Gap Identification (Bundle Diagnostics)**

NDH detects a region where fibers cannot exist.

```
Bundle:
   |---fiber---|   X   |---fiber---|
                ^ gap
```

The “X” marks the region where **no section can be constructed**.

---

# ⭐ **Step 2 — Provisional Fiber Construction (Soft Section)**

NDH constructs a **provisional fiber** — reversible, low‑density.

```
Concept A ----- ~~~~~ ----- Concept B
                 ^
           provisional fiber
```

The `~~~~~` indicates:

- low curvature  
- low density  
- reversible structure

# ⭐ **Step 3 — Resonance Testing (Motif Alignment)**

The provisional fiber tests motif resonance.

ASCII resonance test:

```
Concept A === motif1
              |
              | resonance?
              |
Concept B === motif2
```

If motif1 ↔ motif2 resonate → fiber stabilizes.  
If not → fiber dissolves.

# ⭐ **Step 4 — Fiber Stabilization (Curvature Lock‑In)**

If resonance succeeds, NDH promotes the provisional fiber to a stable fiber.

```
Concept A -----=====----- Concept B
                 ^
             stable fiber
```

`=====` indicates:

- curvature locked  
- density increased  
- adjacency stable

```

```

The gap is now **resolved**, not patched.
