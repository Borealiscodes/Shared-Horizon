# 🌍 **2 — World State Surface**  
Lead term: **world state**

The world evolves after every adventure.

### World State Variables
- **Environmental Curvature (EC)**  
- **Population Despair (PD)**  
- **Hope Index (HI)**  
- **Rift Stability (RS)**  

### Update Equation

\[
WS_{\text{next}} = WS + \Delta EC + \Delta PD - \Delta HI + \Delta RS
\]

This ensures:

- Collapse → world brightens  
- Ascension → world darkens  
- Partial success → mixed consequences  

This is the backbone of Fallout‑style continuity.

---

# 🛡️ **3 — Faction Surface**  
Lead term: **faction arcs**

Factions evolve based on emotional physics.

### Faction Stats
- **Curvature Tolerance (CT)**  
- **Despair Susceptibility (DS)**  
- **Hope Alignment (HA)**  
- **Core Influence (CI)**  

### Drift Equation

\[
F_{\text{next}} = F + \omega \cdot (HA \cdot H_{\text{team}} - DS \cdot \sum D_i)
\]

Interpretation:

- High Hope teams **convert** factions  
- High Despair teams **corrupt** factions  
- Balanced teams **polarize** factions  

This creates branching faction arcs.

---

# 🔧 **4 — Resource Surface**  
Lead term: **resource loops**

Resources become scarce or abundant depending on world state.

### Resource Types
- Stability Shards  
- Memory Anchors  
- Entropy Fuel  
- Rift Keys  

### Economy Equation

\[
R_{\text{value}} = B + \eta \cdot (EC + RS)
\]

As the world destabilizes, resources become more valuable —  
mirroring Fallout’s water, ammo, medicine loops.

---

# ⚖️ **5 — Moral Drift Surface**  
Lead term: **moral drift**

Player choices accumulate into identity.

### Moral Drift Score (MDS)

\[
MDS_{\text{next}} = MDS + \phi \cdot (H_i - D_i)
\]

Paths:

- **Compassion Path** — high Hope  
- **Abyssal Path** — high Despair  
- **Grey Path** — balanced  

NPC reactions, faction alignment, and endings depend on MDS.

---

# 🎮 **6 — Roadmap Flow (Adventure Loop)**  
Lead term: **adventure roadmap**

### **Phase 1 — Trigger**
A rift opens, a faction destabilizes, or a resource crisis emerges.

### **Phase 2 — Descent**
PCs enter a labyrinth using curvature + despair + hope physics.

### **Phase 3 — Fallout**
Update:

- World State  
- Faction Drift  
- Resource Economy  
- Moral Drift  

### **Phase 4 — Branching**
Next adventure depends on:

- Which factions changed  
- Which resources shifted  
- How the world destabilized  
- How PCs drifted morally  

This produces **Fallout‑style cohesion**.

---

# ❄️ **7 — Example Roadmap Arc: “The Choir → The Reactor → The Fracture”**

### Adventure 1 — “Frozen Choir”
Outcome: Collapse  
→ EC↓, HI↑, PD↓  
→ Choir Survivors ally  
→ Ice Priests weaken

### Adventure 2 — “Entropy Reactor”
Because EC↓ and HI↑:  
→ Warm Engineers emerge  
→ Reactor project begins  
→ PCs choose support / sabotage / exploit

### Adventure 3 — “The Fracture”
Depending on Reactor outcome:  
- If supported → RS stabilizes → new labyrinth type  
- If sabotaged → RS destabilizes → catastrophic rift  
- If exploited → faction war → dual labyrinth event

This is **branching, persistent, systemic Fallout‑style storytelling**.
