# 🌲 **Starter Module — “Whisperwood Lantern” (v1.0)**  
*Tier 1 • Emotional Mystery • Autumn Resonance*





## **Module Summary**  
A strange hum echoes through Whisperwood as Autumn deepens.  
Memory lanterns flicker.  
Corruption pressure rises.  
Something is calling Lira Vale.

This module is designed to test:

- NPC Personality Generator  
- Event Engine  
- Seasonal Cycle Model  
- Corruption System  
- Easter Egg Engine  
- Lira Vale’s emotional physics  
- IC narrative flow  

It is short, atmospheric, and perfect for a first run.

### **Act I — The Hum in the Trees**

### **Act II — The Broken Lantern**

NPC interaction + event roll + seasonal influence.

Climax + corruption inversion risk + IC decision.

Resolution + world-state update + next-hook setup.

# 🔮 **5. Act IV — The Lantern Memory**

The broken lantern pulses.

A memory spills out —  
not hers, not his, but familiar.

A woman’s voice:  
“Lira… run.”

### **Checks**
- **Easter Egg Trigger:** 28% (Blooming Memory Egg or Broken Oath Egg)  
- **Drift Gain:** +0.08  
- **Continuity Test:** DC 0.52  
- **Inversion Risk:** Low but present  

### **Choices**
- **Reach toward the memory**  
- **Pull back**  
- **Call the voice’s name**  
- **Try to stabilize the lantern**

# 🕸️ **6. Act V — The Face in the Mist**

The mist thickens.

A silhouette forms —  
the same face she saw years ago  
when the lantern shattered.

But now it’s distorted.

### **Checks**
- **Corruption Pressure:** Medium  
- **Inversion Save:** roll vs 1.50  
- **Event Roll:** 35% (Corruption Bloom Echo)  
- **Drift Gain:** +0.10  

### **Choices**
- **Confront the figure**  
- **Flee**  
- **Use Lantern of First Light**  
- **Call for Rowan**
