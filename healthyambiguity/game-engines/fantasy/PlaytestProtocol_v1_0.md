# 🎮 **Playtest Protocol (Fantasy Engine v1.0)**  
*Runtime Harness • Emotional Physics • Narrative Flow*

## **Takeaway**  
This protocol defines **how to run a live session** using:

- NPC Personality Generator  
- Event Engine  
- Seasonal Cycle Model  
- Corruption System  
- Easter Egg Engine  
- World-State Function W(t)  

It gives you the **turn structure**, **emotional checks**, **event rolls**, **corruption pressure**, and **micro‑event triggers** needed for a stable, meaningful playtest.

---

# 🧭 **1. Playtest Setup**

### **Choose Starting Conditions**
- **Starting Season** → use the Seasonal Cycle Model  
- **Starting Zone** → settlement, wilderness, faction territory  
- **Ambient Rasa** → from zone + season  
- **Corruption Level** → dormant, low, medium, high  
- **Event Bias** → based on season + zone  

### **Initialize World-State W(t)**
- rasa climate  
- corruption pressure  
- seasonal resonance  
- event likelihood  
- settlement mood  
- faction stability  

### **Spawn the Player Character**
Use the NPC Personality Generator to create:

- primary rasa  
- secondary rasa  
- continuity field  
- drift threshold  
- seasonal resonance profile  
- corruption susceptibility  
- faction alignment  
- settlement origin  

---

# 🔁 **2. Turn Structure (Core Loop)**

Each turn consists of **six phases**, each represented as a Guided Link.

1. **Resonance Phase**  
   Seasonal + environmental emotional influence.

2. **NPC Emotional Update**  
   Drift, continuity, rasa shifts.

3. **Event Roll**  
   Check for environmental, faction, settlement, monster, magic, or corruption events.

4. **Corruption Pressure Check**  
   Inversion, fragmentation, overload, bleed.

5. **Easter Egg Trigger Check**  
   Rare micro‑events based on multi‑condition alignment.

6. **Player Action Phase**  
   Exploration, dialogue, combat, rituals, travel, rest.

This loop repeats every turn.

---

# 🔮 **3. Emotional Update Rules**

NPC emotional physics update using:

\[
U_{\text{emotional}} = \Delta_{\text{rasa}} + \Delta_{\text{drift}} + \Delta_{\text{continuity}} + \Delta_{\text{resonance}} + \Delta_{\text{inversion}}
\]

### **Rasa Update**
- seasonal resonance  
- event influence  
- corruption inversion  
- NPC interactions  

### **Drift Update**
- events  
- corruption  
- seasonal instability  
- emotional overload  

### **Continuity Update**
- settlement mood  
- faction stability  
- corruption pressure  

NPCs evolve emotionally each turn.

---

# ⚡ **4. Event Roll Procedure**

Roll once per turn:

- **Environmental**  
- **Faction**  
- **Settlement**  
- **Monster**  
- **Magic Tradition**  
- **Corruption**

Event likelihood is modified by:

- season  
- zone  
- corruption level  
- NPC drift  
- ambient rasa  

If an event triggers, apply:

- mechanical impact  
- emotional impact  
- world-state delta  

---

# 🕸️ **5. Corruption Pressure Check**

Evaluate corruption vectors:

- inversion  
- fragmentation  
- overload  
- bleed  

If corruption pressure exceeds threshold:

- NPC corruption susceptibility increases  
- zone corruption level rises  
- corruption events become more likely  
- Easter Egg corruption anomalies may trigger  

---

# 🥚 **6. Easter Egg Trigger Check**

Check for multi‑condition alignment:

- rasa combination  
- drift threshold  
- continuity band  
- season  
- corruption state  
- location  
- event context  

If aligned → trigger a rare micro‑event.

Examples:

- hidden lore fragment  
- NPC personality reveal  
- dimensional anomaly  
- secret mechanic  
- puzzle fragment  

---

# 🎭 **7. Player Action Phase**

Player chooses an action:

- explore  
- speak  
- fight  
- hide  
- rest  
- perform ritual  
- travel  
- investigate  
- interact with NPCs  
- attempt emotional alignment  

Actions modify:

- drift  
- continuity  
- rasa  
- event likelihood  
- corruption susceptibility  

---

# 🌌 **8. End-of-Turn World-State Update**

Update W(t):

- rasa climate  
- corruption pressure  
- seasonal resonance  
- event likelihood  
- settlement mood  
- faction stability  
- NPC emotional state  

This ensures the world evolves coherently.
