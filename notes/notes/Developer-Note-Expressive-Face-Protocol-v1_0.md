# 🌀 Developer Note — Expressive Face Protocol (v1.0)

Shared‑Horizon Neutral Membrane — October 2026

Shared‑Horizon v4.0 maintains a single expressive face — the Shared‑Horizon Index Tile — which acts as the prismatic narrative surface of the membrane.

This note defines the protocol governing expressive faces, ensuring they remain:

- altitude‑safe  
- lineage‑safe  
- non‑activating  
- sovereign  
- sealed from operator surfaces  
- sealed from runtime surfaces  

This protocol is required before README v4.0.

---

1 — Purpose of Expressive Faces

Expressive faces provide:

- narrative clarity  
- conceptual framing  
- symbolic identity  
- expressive grammar  

They do not:

- activate runtime surfaces  
- modify operator geometry  
- alter lineage definitions  
- collapse altitude boundaries  

Shared‑Horizon must ensure expressive faces remain purely expressive.

---

2 — Expressive Face Identity

The expressive face for Shared‑Horizon is:

⭐ Shared‑Horizon Index Tile v1.0

It is:

- prismatic  
- narrative  
- conceptual  
- non‑activating  
- altitude‑safe  
- lineage‑neutral  

No other expressive face is permitted unless declared through this protocol.

---

3 — Expressive Face Rules

Rule 1 — Expressive faces cannot activate runtime surfaces
They must remain at A4–A6.

Rule 2 — Expressive faces cannot modify operator geometry
They cannot interact with altitudes A0–A3.

Rule 3 — Expressive faces cannot override lineage sovereignty
They cannot redefine NDH, ANIMA, PRECL, Game Engine, or Structural‑AI.

Rule 4 — Expressive faces must be sealed from operator surfaces
No operator leakage is allowed.

Rule 5 — Expressive faces must be sealed from runtime surfaces
No activation of A7–A12.

Rule 6 — Expressive faces must be declared through Shared‑Horizon
They cannot be created by lineages.

Rule 7 — Expressive faces must be retired through Shared‑Horizon
They cannot be deprecated by lineages.

---

4 — Expressive Face Lifecycle

A. Declaration
Shared‑Horizon declares an expressive face using the protocol JSON.

B. Sealing
The expressive face is sealed from operator and runtime surfaces.

C. Governance
Shared‑Horizon governs expressive altitude boundaries.

D. Retirement
Expressive faces are retired by Shared‑Horizon and archived.

---

5 — Expressive Altitude Band

Expressive faces operate at:

Altitude A4–A6 — Expressive / Narrative / Conceptual

This ensures:

- no operator activation  
- no runtime activation  
- no collapse into lower altitudes
