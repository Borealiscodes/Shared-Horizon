Overview

Shared‑Horizon is a research framework designed to help people understand how different AI systems — each built with different assumptions, architectures, and mathematical foundations — can be compared, documented, and reasoned about without interfering with one another.

It provides a neutral space where:

- geometric AI systems

This framework does not run or activate any AI system.  
It simply provides a structured way to understand how they relate.
