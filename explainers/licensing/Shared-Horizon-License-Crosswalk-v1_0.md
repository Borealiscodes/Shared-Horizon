# 🧩 **Shared‑Horizon License Crosswalk v1.0 (Artifact)**

## 🌤️ Overview  
Licenses behave like **atmospheric layers** in Shared‑Horizon:

- **MIT** → clear sky (permissive, commercial‑friendly)  
- **ANIMA Non‑Commercial** → cloud ceiling (protective, lineage‑preserving)  
- **Apache‑2.0** → structured sky (permissive but with explicit patent rules)  
- **GPL‑3.0** → storm front (strong copyleft, derivative obligations)  
- **Shared‑Horizon Governance** → calm layer (non‑activating, sovereignty‑preserving)  
- **NDH Sovereignty Rules** → high‑discipline stratosphere (altitude‑restricted)

This Crosswalk explains how these layers interact without mixing altitudes or violating intent.

## 🧭 **2 — Crosswalk Logic (Resolver‑Safe)**

### **A — MIT ↔ Shared‑Horizon**
MIT can be used inside Shared‑Horizon **only at narrative or tooling altitude**.  
It cannot govern NDH solvers or sovereignty surfaces.

### **B — ANIMA ↔ Shared‑Horizon**
ANIMA’s Non‑Commercial License is compatible **only at narrative altitude**.  
It must remain isolated in `LICENSES/` and referenced, not embedded.

### **C — Apache‑2.0 ↔ Shared‑Horizon**
Apache‑2.0 is compatible with Shared‑Horizon’s narrative surfaces and can govern:

- documentation tools  
- build scripts  
- non‑solver utilities

### **D — GPL‑3.0 ↔ Shared‑Horizon**
GPL‑3.0 is **not compatible** with NDH or Shared‑Horizon metastructural surfaces because:

- copyleft would force NDH solvers to become GPL  
- sovereignty would be violated  
- altitude discipline would collapse

GPL may only appear in **external references**, never in NDH or Shared‑Horizon code.

### **E — NDH Sovereignty Rules**
NDH’s internal governance is **not a license** but a **sovereignty membrane**.  
It requires:

- non‑commercial usage  
- non‑activation  
- altitude discipline  
- lineage preservation  
- membrane separation

It is compatible with ANIMA’s Non‑Commercial License but **not** with MIT or GPL for solver surfaces.

- NDH sovereignty is **stratosphere** — disciplined, thin, high‑altitude.

Each layer must remain distinct to avoid turbulence.
