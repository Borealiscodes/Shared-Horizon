# **2 — Purpose of This Cross‑Analysis**  
🎯

NDH has three major semantic surfaces:

- **Meta‑Ontology** → meaning‑of‑meanings  
- **Meta‑Taxonomy** → classification‑of‑classifications  
- **Visual Grammar** → visual‑language‑of‑surfaces  

These surfaces operate at **different altitudes**, in **different lanes**, with **different responsibilities**, but they must remain **coherent** and **non‑drifting**.

This cross‑analysis explains:

- how they differ  
- how they cooperate  
- how they bind  
- how they avoid altitude drift  
- how they preserve sovereignty  
- how they support future JSON artifacts

# **5 — Binding Logic (How They Connect)**  
🔗

### **A — Meta‑Ontology ↔ Meta‑Taxonomy**  
- Meta‑Ontology describes semantic surfaces.  
- Meta‑Taxonomy classifies those surfaces.  
- They form a **semantic dual spine**.

### **B — Meta‑Ontology ↔ Visual Grammar**  
- Ontologies require glyphs for altitude, lane, and membrane.  
- Visual Grammar provides those glyphs.  
- Meta‑Ontology binds to Visual Grammar via `visual_binding_id`.

### **C — Meta‑Taxonomy ↔ Visual Grammar**  
- Taxonomies require glyphs for lineage, altitude, and class.  
- Visual Grammar provides those glyphs.  
- Meta‑Taxonomy binds to Visual Grammar via `altitude_class` and `grammar_class`.

### Key Insight  
Visual Grammar is the **glyph layer** for both Meta‑Ontology and Meta‑Taxonomy.
