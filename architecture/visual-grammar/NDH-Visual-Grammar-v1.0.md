# **2 — Purpose of the Visual Grammar**  
🎯🖼️

The NDH Solver Stack now spans:

- semantic surfaces  
- structural surfaces  
- narrative explainers  
- metastructural artifacts  

To keep these coherent, the system needs a **visual language** — a grammar of shapes, colors, glyphs, and arrows that:

- signals altitude  
- preserves lane purity  
- enforces membrane discipline  
- marks sovereignty  
- clarifies geometry  
- guides ingestion flow  

This document defines that grammar.

---

# **3 — Core Visual Principles**  
🌈📐

### **A — Altitude Clarity**  
Each altitude band (A1–A9) has a distinct glyph + color.

### **B — Lane Purity**  
Each lane has a canonical shape.

### **C — Sovereignty Preservation**  
Sovereignty glyphs must be visually dominant.

### **D — Membrane Discipline**  
Membrane icons must clearly indicate protection or constraint.

### **E — Reversibility**  
REV‑2 glyph must be visually reversible.

### **F — Resolver‑Safe Arrows**  
Arrows must indicate direction, altitude flow, and semantic inheritance.
