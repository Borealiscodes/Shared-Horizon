# 🎨 **1 — Purpose of NDH Visual Grammar**

NDH Visual Grammar defines the **canonical visual language** used across Shared‑Horizon. It provides:

- glyphs  
- lanes  
- sovereignty icons  
- membrane states  
- geometry primitives  
- documentation primitives  
- resolver arrows  
- altitude glyphs  
- shape grammar  
- inheritance rules  

It is the **root grammar** for:

- **HealthyAmbiguity Rendering Grammar**  
- **Fantasy Engine Rendering Grammar**  
- **Spectral Visual Grammar**  

NDH Visual Grammar is the **A5 expressive‑formal layer** that governs all rendering surfaces from A4 to A7.

# ➡️ **8 — Resolver Arrow Semantics**

NDH Visual Grammar defines arrow semantics:

- **relation → (U+27A1)**  
- **transformation ↪ (U+21AA)**  
- **reversible ⇄ (U+21C4)**
