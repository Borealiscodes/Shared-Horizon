# 🌐 **1 — Purpose of Shared‑Horizon**

Shared‑Horizon is a **multi‑layer ecosystem** containing:

- experimental runtime architecture  
- capsule governance membranes  
- GPU runtime spine  
- narrative/game ecosystem (HealthyAmbiguity)  
- rendering grammar expressive layer  
- charters and normative declarations  
- legal surfaces  
- explainers and crosswalks  

Shared‑Horizon is **not** a single system.  
It is a **constellation of membranes**, each with its own altitude, ontology, and safety rules.

This README v2.0 provides the **full taxonomy, ontology, and visual grammar** for the entire ecosystem.
