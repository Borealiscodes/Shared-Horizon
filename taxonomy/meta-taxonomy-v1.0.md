## ⭐ **3 — Core Classes**

Each class is a **Guided Link**, because each may become a future artifact.

- **MetaFamily** — highest‑order grouping of semantic surfaces.  
- **MetaGenus** — structural grouping within a MetaFamily.  
- **MetaSpecies** — atomic semantic surface class.  
- **SemanticSurfaceClass** — the actual surface type (ontology, taxonomy, schema, grammar).  
- **TaxonomicBinding** — binding rules between surfaces and classes.  
- **EvolutionLineage** — versioned lineage of semantic surfaces.  
- **AltitudeClass** — altitude‑correct classification envelope.  
- **GrammarClass** — classification of grammar surfaces (non‑coercive, non‑directive, etc.).

These classes define the **semantic classification universe**.

## ⭐ **4 — Class Definitions**

### **MetaFamily**  
Highest‑order grouping.  
Defines the “semantic continent” a surface belongs to.

Examples:  
- Ontological Family  
- Taxonomic Family  
- Schema Family  
- Grammar Family  

### **MetaGenus**  
Structural grouping within a MetaFamily.  
Defines the “semantic region.”

Examples:  
- Structural Genus  
- Expressive Genus  
- Governance Genus  

### **MetaSpecies**  
Atomic semantic surface class.  
Defines the “semantic organism.”

Examples:  
- Ontology v1.0  
- Taxonomy v1.0  
- Schema v1.0  
- Grammar v1.0  

### **SemanticSurfaceClass**  
The actual surface type.  
Defines the “semantic phenotype.”

### **TaxonomicBinding**  
Rules for binding surfaces to classes.  
Ensures drift‑neutral classification.

### **EvolutionLineage**  
Versioned lineage of semantic surfaces.  
Defines semantic ancestry.

### **AltitudeClass**  
Altitude envelope for classification.  
Ensures altitude discipline.

### **GrammarClass**  
Classification of grammar surfaces.  
Ensures non‑coercive, non‑directive grammar.
