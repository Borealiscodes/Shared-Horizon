## ⭐ **1 — Purpose of This Folder**

This folder contains **Capsules**, which are:

- **binding membranes**  
- **governance surfaces**  
- **activation guards**  
- **runtime adapters**  
- **non‑activating descriptive interfaces**

Capsules do **not** execute computation.  
They **govern** how computation *would* occur in a safe, altitude‑controlled manner.

Capsules sit **above** the Runtime‑Spine and **below** the Shared‑Horizon root, forming the **membrane layer** of ANIMA.
