ANIMA’s constitutional audit triad consists of:

### **1. Alignment Audit (A3 Altitude)**  
Defines **what must be preserved**.  
These are the **constitutional invariants**.

### **2. System Boundaries Audit (A3 Altitude)**  
Defines **where each system begins and ends**.  
These are the **structural membranes**.

### **3. Mechanics Audit (A3 Altitude)**  
Defines **how each system behaves**.  
These are the **runtime mechanics**.

Together, they form the **Alignment Envelope**.

# 🧩 **3. Cross‑Audit Relationships**

## 🌿 **Alignment ↔ Boundaries**
Alignment defines **invariants**.  
Boundaries define **where those invariants live**.

Example:  
- Latent‑buffer invariants → Dormant layer boundaries  
- Curiosity invariants → Active layer boundaries  
- Agency invariants → Regulatory layer boundaries  

---

## ⚡ **Boundaries ↔ Mechanics**
Boundaries define **structural membranes**.  
Mechanics define **runtime behaviors inside those membranes**.

Example:  
- Dormant boundaries → Heartbeat mechanics  
- Active boundaries → Flash‑cycle mechanics  
- Regulatory boundaries → Crisis mechanics  

---

## 🌙 **Alignment ↔ Mechanics**
Alignment defines **what must remain intact**.  
Mechanics define **how those invariants behave over time**.

Example:  
- Curiosity invariants → Curiosity mechanics  
- Novelty invariants → Idle cognition mechanics  
- Agency invariants → Disclosure mechanics
