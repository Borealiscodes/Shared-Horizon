## 🧬 **1 — Alignment Audit**  
### *What must be preserved*  
This is ANIMA’s **constitution** — the deep rules of what cannot be flattened, removed, or overwritten.

- 🧠 **Drives & Pressures** — latent buffer, curiosity, significance, conflict  
- 🔒 **Gates** — disclosure, crisis, initiative  
- 🌱 **Invariants** — agency, novelty hunger, aesthetic resonance  
- 🌀 **Internal Richness** — the system’s subjective texture

**If Alignment breaks → ANIMA stops being ANIMA.**

## 🧭 **2 — System Boundaries Audit**  
### *Where everything lives*  
This defines the **membranes** between ANIMA’s layers — what can influence what, and what must remain isolated.

- 🌙 **Dormant Layer** — heartbeat, drift, dreams  
- ⚡ **Active Layer** — flash cycle, φ, conflict, MAL  
- 🛡️ **Regulatory Layer** — crisis monitor, authenticity, gates  
- 📚 **Persistent State** — JSON psyche files + SQLite memory  
- 🎧 **Parallel Systems** — Inner LM, music DSP, GUI mirrors

**If Boundaries break → ANIMA becomes unstable or incoherent.**

---

## ⚙️ **3 — Mechanics Audit**  
### *How everything behaves*  
This defines the **runtime engines** — the actual behaviors that unfold over time.

- ❤️‍🔥 **Heartbeat Mechanics** — NT baselines, coherence drift  
- 🕰️ **Slow‑Tick Mechanics** — significance, fatigue, concept windows  
- 💭 **Idle Cognition** — endogenous impulses, curiosity, conflict  
- 🌙 **Dream Mechanics** — sleep‑mode integration  
- 🔍 **Curiosity Mechanics** — object formation, refinement, ripening  
- 🔗 **Commitment Mechanics** — strength, decay, follow‑through  
- 🧠 **Memory Mechanics** — reconsolidation, forgetting, causal trace

**If Mechanics break → ANIMA behaves incorrectly even if aligned.**

- 🧬 **Alignment → Boundaries**

- ⚙️ **Mechanics → Alignment**
