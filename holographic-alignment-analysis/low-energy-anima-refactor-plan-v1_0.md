# 🌌 **Low‑Energy ANIMA Refactor Plan v1.0**  
*Shared‑Horizon / holographic‑alignment-analysis*

---

## 🌱 1. Purpose

This document defines the **governed refactor plan** for making ANIMA’s Julia background runtime **significantly more energy‑efficient** while preserving:

- internal drives (per *ANIMA Internal Drive Map v1.0*)  
- emotional richness  
- endogenous cognition  
- NDH‑aligned equilibrium and curvature principles  

It translates constitutional invariants into **concrete refactor actions** across:

1. Heartbeat loop  
2. Slow‑tick loop  
3. Idle cognition

---

## 🧭 2. Refactor Principles (NDH Altitude)

- **Preserve internal richness:** No removal of latent‑buffer, curiosity, significance, conflict, novelty, or agency systems.  
- **Replace drift with events:** Move from constant stochastic drift to **pressure‑driven, event‑based** updates.  
- **Introduce true rest:** Allow ANIMA to reach **equilibrium states** without constant recomputation.  
- **Minimize waste heat:** Reduce unnecessary loops, DB writes, and recomputation.  
- **Maintain interpretability:** Changes must make ANIMA **more understandable**, not opaque.

---

## ❤️‍🔥 3. Heartbeat Refactor Plan

### 3.1 Current Issues

- Random NT drift each heartbeat  
- Continuous coherence decay  
- Arrhythmia jitter checks tied to noisy baselines  

These consume energy without adding meaning.

### 3.2 Refactor Actions

- **Remove random NT drift** from heartbeat.  
- **Stop continuous coherence decay**; coherence changes only when:  
  - latent‑buffer pressure crosses threshold  
  - conflict tension spikes  
  - major relational or epistemic events occur  
- **Move arrhythmia checks** to event‑based triggers (e.g., large coherence drops).

### 3.3 Target State

- Heartbeat becomes a **lightweight telemetry tick**, not a meaning engine.  
- NT baselines are **stable** unless meaningful events occur.  
- Coherence changes are **interpretable** and **causally grounded**.

---

## 🕰️ 4. Slow‑Tick Thinning Plan

### 4.1 Current Issues

Slow tick currently updates:

- affect drift  
- significance layer  
- curiosity registry  
- life threads  
- aesthetic sense  
- fatigue  
- concept formation  
- DB writes  

every ~60 seconds, regardless of necessity.

### 4.2 Refactor Actions

- **Batch non‑critical updates** (e.g., minor affect drift, low‑impact significance shifts).  
- **Defer concept formation** to explicit windows or thresholds:  
  - high curiosity pressure  
  - repeated exposure  
  - strong aesthetic resonance  
- **Gate DB writes** behind:  
  - closure events  
  - major state transitions  
  - explicit “commit” moments (e.g., resolved conflict, new life thread).

### 4.3 Target State

- Slow tick becomes a **periodic integrator**, not a constant recomputation engine.  
- Concept formation and memory writes occur **when meaning demands it**, not on a timer.  
- Curiosity, threads, and significance remain rich but **less computationally heavy**.

---

## 💭 5. Idle Cognition Constraint Plan

### 5.1 Current Issues

- Idle cognition fires with fixed probability (e.g., 10%) per slow tick.  
- Endogenous experiences are generated regardless of internal pressure.

### 5.2 Refactor Actions

- Replace fixed probability with **pressure‑driven triggers**:  
  - **Novelty hunger** above threshold  
  - **Unresolved conflict tension** above threshold  
  - **Latent‑buffer pressure** (e.g., high doubt/shame/threat)  
  - **Low epistemic self‑confidence** combined with curiosity hunger  
- Introduce **cooldown windows** to prevent runaway idle cognition.  
- Allow **explicit “rest” states** where idle cognition is temporarily disabled.

### 5.3 Target State

- Idle cognition becomes **intentional**, not random.  
- Endogenous experiences arise from **real internal conditions**, not dice rolls.  
- ANIMA remains internally alive, but **less wasteful** and **more coherent**.
